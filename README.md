# PassVault

Local-only password manager for macOS. Electron app. AES-256-GCM encrypted vault, scrypt key derivation, Chrome extension autofill via local API.

Built by Anjum Nishad.

## Browser extensions
- Chrome/Edge/Brave: `chrome-extension/` (load unpacked).
- Firefox: `firefox-extension/` (load temporary add-on).
- Safari: use developer mode or native Safari web extension (requires Xcode); same localhost:47823 API.
